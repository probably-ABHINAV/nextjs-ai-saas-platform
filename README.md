AI-powered SaaS platform with Next.js 14, Supabase, and OpenAI integration

## ✨ Tech Stack

- **Next.js 14**
- **Supabase**
- **Tailwind CSS**
- **TypeScript**
- **OpenAI**
- **Stripe**
